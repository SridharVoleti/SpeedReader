# Role 3 Independent QA — Assessment Semantic QA

**Reviews:** immutable `ASSESSMENT` candidate.

Independently verify every item against the approved passage and blueprint. For each scored item, identify the exact passage evidence, verify the marked answer is correct, and test whether any distractor is also defensible. Ambiguity is a BLOCKER.

Check item count/type, primary designation, P-level intent, no outside knowledge, no trick questions and learner-confidence rules.

## Routing

- Item construction/answer ambiguity -> Role 3.
- Passage cannot support the required assessment -> Role 2.
- Blueprint/canonical contradiction -> canonical owner.
