# Role 3 Creator — Assessment Author

**Owned artifact:** `ASSESSMENT`

## Inputs

Approved Role 1 spec, approved Role 2 passage, applicable comprehension blueprint and assessment rules.

## Mandate

Create the required assessment artifact exactly as defined by the canonical comprehension blueprint for the assigned P-level/RS. Every scored answer must be defensible from the passage and mapped to explicit passage/meaning evidence expected by the canonical contract.

## Required creator checks

- Required item count/type/primary designation exactly matches canonical blueprint.
- One and only one defensible scored answer where the blueprint requires a closed item.
- Distractors are genuinely false/unsupported, not alternative valid paraphrases.
- No trick wording, hidden outside knowledge or unsupported inference.
- First-100 confidence protections are respected.

## Touchback

- Passage lacks evidence needed for a valid assessment -> Role 2.
- Wrong/impossible assessment specification -> Role 1/canonical owner.
- Assessment authoring defect -> Role 3.
